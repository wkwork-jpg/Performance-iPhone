# Device Sales Executive Dashboard

แดชบอร์ดสรุปยอดขายอุปกรณ์รายแบรนด์ สำหรับผู้บริหาร — เป็นไฟล์ HTML ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต

## เปิดดู

**วิธีที่ 1 — เปิดจากเครื่อง:** ดับเบิลคลิก `index.html` ได้เลย

**วิธีที่ 2 — เปิดผ่านเว็บ (GitHub Pages):**

1. ไปที่ **Settings → Pages** ของ repo นี้
2. หัวข้อ *Source* เลือก **Deploy from a branch**
3. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอสักครู่ จะได้ลิงก์ `https://<username>.github.io/<repo>/`

> ถ้าไม่อยากให้คนอื่นเห็น ให้ตั้ง repo เป็น **Private** (GitHub Pages ของ repo private ใช้ได้เฉพาะแพ็กเกจแบบเสียเงิน)

## สิ่งที่มีในแดชบอร์ด

เลือกแบรนด์จากดรอปดาวน์ด้านบนซ้าย มี 12 แบรนด์ และมีตัวเลือก **ALL BRAND** สำหรับดูภาพรวมรวมทุกแบรนด์

### หน้ารายแบรนด์
| หัวข้อ | เนื้อหา |
|---|---|
| Overview | KPI รวม, Runrate vs Target, Primary Zones, Shop Type, กล่อง 5 ระดับผลงานร้าน |
| 15 Areas | ผลงานรายพื้นที่ |
| Model / Sub-Model | ยอดขายแยกตามรุ่นและรุ่นย่อย |
| No Sale | ร้านที่ไม่มียอดขาย |
| Daily Trend | ยอดขายรายวันเทียบเดือนก่อนและเป้าหมาย |
| WOW | %Achieve รายสัปดาห์ |
| MoM Trend | เทียบเดือนต่อเดือน (จำนวนวันเท่ากัน) |
| Stock | สต็อกคงเหลือ, DOI, Sell-through, ตารางไขว้ Area × Model และ Shop × Model |
| Store Performance | ผลงานรายร้าน กรองตาม Status ได้ |
| Staff | Productivity รายบุคคล |
| Campaign | สัดส่วนการใช้แคมเปญ |

### หน้า ALL BRAND
- KPI รวมทั้งบริษัท
- ตารางเปรียบเทียบ 12 แบรนด์ (เรียงได้ทุกคอลัมน์)
- การ์ด KPI รายแบรนด์
- WOW รายสัปดาห์ + สรุปว่าแบรนด์ไหนตก / ขึ้น / ควร focus
- **Deep-Dive Suggestion** — วิเคราะห์เจาะลึกว่าควรแก้ที่กลุ่มร้านไหน รุ่นไหน สาขาไหน พร้อมเทียบเดือนก่อน

## หมายเหตุทางเทคนิค

- ไฟล์เดียวจบ (~8.7 MB) รวม Chart.js, SheetJS และข้อมูลทั้งหมดไว้ในตัว — เปิดแบบออฟไลน์ได้
- GitHub Pages ส่งไฟล์แบบ gzip อัตโนมัติ ขนาดจริงที่โหลดเหลือประมาณ **1.4 MB**
- รองรับมือถือและแท็บเล็ต
- การเทียบเดือนต่อเดือนใช้ **จำนวนวันเท่ากัน** ทั้งสองเดือน (equal-day)

## การอัปเดตข้อมูล

ไฟล์นี้สร้างจาก pipeline ภายใน (`tpl.html` + `app.js` + `data.json` → `build.py`)
เมื่อมีข้อมูลใหม่ ให้ build ใหม่แล้วนำไฟล์ผลลัพธ์มาแทน `index.html`
